# Práctica 1

**Autor:** Francisco Yael Miguel Solis

## Descripción

En esta práctica se desarrolló una aplicación básica utilizando Node.js con el objetivo de comprender los fundamentos de las aplicaciones distribuidas, la estructura de un proyecto en JavaScript y la ejecución de procesos en un entorno cliente-servidor.

## Objetivos

- Comprender el funcionamiento de Node.js.
- Implementar una aplicación básica en JavaScript.
- Familiarizarse con la estructura de proyectos distribuidos.
- Ejecutar y probar aplicaciones desde la línea de comandos.

## Tecnologías Utilizadas

- Node.js
- JavaScript
- npm
